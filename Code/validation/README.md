# Validation material

This directory contains a compact subset of the validation material associated with the manuscript.

- `final/`: analytically controlled reference cases and an independent exact-identity checker.
- `stablewein/`: scripts, convention checks, inputs, and retained results for the targeted comparison with the public StableWein implementation.
- `extreme_scale/negative_normalized_classification.json`: a stored audited decision used by the fast regression suite.

These files support reproducibility but do not constitute an independent formal proof of the universal completeness argument.
